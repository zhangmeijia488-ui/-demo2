# SpotHire Radar Demo

这是一个纯前端的招聘与人才雷达 Demo，遵循 SpotCrime 的数据工程思路：

- 多源聚合：岗位与人才数据统一标准化；
- 地理打点：根据经纬度在地图上呈现；
- 区域过滤：按照距离进行筛选；
- 智能推荐：通过规则引擎模拟 AI 匹配；
- 可视化：地图看板展示 Top 3 推荐。

## 目录结构

```text
spotjob-radar-demo/
├── index.html          # SPA 页面与 Tailwind/Leaflet 引入
├── app.js              # 数据生成、筛选、AI 推荐与地图渲染逻辑
├── README.md           # 运行说明与部署说明
└── .vscode/            # 可选：本地开发配置（若需要）
```

## 运行方式

### 方式 1：本地 Python 静态服务器

```bash
cd /Users/hutt_/产品原型或Demo/spotjob-radar-demo
python3 -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000/
```

### 方式 2：Vercel 部署

1. 将这个目录中的所有文件上传到新项目。
2. 选择 `Static Site` / `Vercel` 直接部署。
3. 由于本 Demo 为纯前端静态页面，不依赖后端，可直接上线。

## 设计亮点

- 左侧控制面板：身份切换、距离筛选、AI 推荐、统计摘要。
- 右侧地图：蓝色岗位 / 橙色人才 / 金色推荐高亮。
- Tooltip：包含岗位或人才简报、薪酬、技能标签、距离与反馈。
- AI 规则：支持输入简历标签，例如 “3年AI产品经理”.

## 伦理与合规提醒

本 Demo 重点展示地图聚合分析思路，而不是个体标签化判断。建议在真实生产环境中：

- 仅做群体聚合与市场分析，不对个人贴“风险标签”；
- 对候选人/岗位数据做最小权限控制；
- 任何真实招聘场景都应遵守劳动法、个人信息保护法等相关规定。
